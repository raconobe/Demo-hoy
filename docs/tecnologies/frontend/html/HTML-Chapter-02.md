# Chapter 2: Text and Semantic Tags

Semantics in HTML give meaning to the web page rather than just presentation.

## Common Semantic Elements
- `<header>`: Represents introductory content or a navigation bar.
- `<main>`: Specifies the dominant content of the `<body>`.
- `<footer>`: Represents a footer for its nearest sectioning content.

## Example Usage
```html
<main>
    <article>
        <h2>Understanding Semantics</h2>
        <p>Semantic tags improve accessibility and SEO.</p>
    </article>
</main>
